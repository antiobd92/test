# Learning to Code

A personal programming course, tracked in files.

## For the student

| Folder | What is in it |
|---|---|
| `curriculum/roadmap.md` | the path: Stage 0 (hello world) to Stage 9 (contests) |
| `curriculum/resources.md` | free MIT / Harvard / Princeton / Berkeley courses, by stage |
| `knowledge/` | what you have **proven** you know |
| `struggles/` | what you are stuck on right now, and what you have beaten |
| `exercises/` | your code |
| `student/` | your profile and the session log |

Start a session by opening Claude Code in this folder and saying **"let's start today's
session."** The tutor reads your record, quizzes you on what is due, and picks up where you
left off.

The tutor will not give you answers. That is on purpose — the struggle is the part where
learning happens. It will discuss, hint, and shrink the problem until you can solve it.
You write every line of your own code.
