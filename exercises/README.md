# Exercises

The student's own practice code. **Only the student's code lives here.** If a file was
written by the tutor, it does not belong in this folder.

## Layout

`exercises/<language>/<stage>-<topic>-<name>.<ext>`

Example: `exercises/python/1-loops-times_table.py`

## Rules

- Every session ends with one exercise assigned here.
- Keep failed and messy attempts. The history is evidence of growth, and old code is the
  best material for the Debug check later.
- Working code from a blank file is what the Build check in `knowledge/` points at.
- From Stage 3 onward, exercises come with their own test cases, written by the student
  before the solution.
